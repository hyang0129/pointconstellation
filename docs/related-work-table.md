# Related-work table

Last reviewed: 2026-08-26.

This is a comparison map, not evidence of novelty or reproduced performance.
“Transmitted” means the per-instance information made available to the decoder
in the cited work; it does not mean that this repository has reproduced the
paper's bitstream. “No codec message” marks work evaluated as representation
learning, sampling, reconstruction, or generation rather than compression.

Every entry is currently marked `[unverified]` because the repository does not
record a Point Constellation paper author personally checking the row against
the complete primary paper and released code. Remove that marker only after
such a check. A `?` records an unresolved fact; it is not an invitation to infer
one from a secondary source. Qualitative rate descriptions are used where exact
serialized rate points have not been checked.

## Novelty boundary

As revised by the review, the novelty boundary is **coordinate-only latent + shared frozen decoder + decoder-aware selection, counted bitstream**. This boundary is conjunctive:
coordinate-only simplification alone, a point-based decoder alone, or
semi-amortized optimization alone is prior art. In particular, the
decoder-gradient mechanism belongs to family 1; it must be described as an
application of encoder-side iterative/semi-amortized inference to legal
point-set selection, not as a new general inference principle. Any paper claim
must still distinguish free coordinates, strict learned subsets, and post-hoc
projection, and must compare actual serialized bits including metadata and any
amortized model cost.
