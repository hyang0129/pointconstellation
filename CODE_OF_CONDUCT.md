# Code of conduct

We want this project to be a welcoming place for careful, constructive
research. Be respectful, critique ideas and evidence rather than people, and
assume good faith while still asking for reproducible support for technical
claims.

Harassment, discrimination, personal attacks, doxxing, and sustained disruptive
behavior are not acceptable in project spaces. Maintainers may edit or remove
contributions and temporarily or permanently exclude participants whose
behavior harms the community.

Report conduct concerns privately to the repository owner. Reports will be
handled as confidentially and promptly as practical.
